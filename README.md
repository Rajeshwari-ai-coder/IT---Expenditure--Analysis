
# IT Expenditure Analysis

## Overview
This project analyzes IT expenditure data to compare Actual, Forecast, and Plan costs across Regions, IT Areas, and Business Areas. The analysis helps in understanding cost variations and budgeting efficiency.

## Dataset
- IT Expenditure Dataset (Actual, Forecast, Plan, Region, IT Area, Business Area)

## Visualizations
1. **Actual vs Forecast vs Plan** - Overall cost comparison (Actual ~555M)
2. **Region-wise Expenditure** - Spending analysis by region
3. **IT Area-wise Expenditure** - Cost breakdown by IT departments
4. **Business Area-wise Expenditure** - Spending across business units

## Tools Used
- Tableau Public for Visualization
- Data Analysis

## Insights
- Actual expenditure is lower than Forecast and Plan
- Identified high-spending regions and areas for cost optimization
